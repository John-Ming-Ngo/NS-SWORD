# Notice

NS-SWORD contains code developed from the lightcurve code of Coire Cadeau and later modified and expanded by John Ming Ngo. 

The PVLS Python model and its weights were copied and adapted from the repository of Gregory Papigkiotis and collaborators:

    https://github.com/gregoryPapi/Universal-description-of-the-NS-surface-using-ML

    That work comes from G. Papigkiotis, G. Vardakas, A. Likas, and N. Stergioulas, *Physical Review D* **111**, 083056 (2025). The PVLS model is not my work. Credit belongs to its authors.

RNS and the hydrogen atmosphere table are not included, and need to be added to make the code work. See the readme for more information.
