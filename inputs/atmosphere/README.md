# Hydrogen atmosphere table

The hydrogen spectrum calculation requires Wynn Ho's hydrogen atmosphere table, named `nsx_H_v200804.out`. This file is not included because it is too large for this repository and must be obtained from an authorized source.

If used, either place the file here:

```text
inputs/atmosphere/nsx_H_v200804.out
```

or give its path to the full-run script with `--atmosphere`.
